# Система Рекомендаций Книг на Основе Датасета GoodBooks-10k
![Books](books.png) 
## Описание Проекта

Этот учебный проект реализует прототип книжного рекомендательного сервиса с использованием датасета **Goodbooks-10k**. Датасет включает отзывы пользователей, информацию о книгах и теги. Проект демонстрирует структурированный подход от подготовки данных и разведочного анализа (**EDA**) до реализации и оценки моделей рекомендаций: неперсонализированные (на основе популярности), контентные (**TF-IDF** с тегами), коллаборативная фильтрация (**item-based CF**) и матричное разложение (**SVD**). Цель — сравнить методы, адаптировать их к проблемам (разреженность данных, смещение популярности, "холодный старт") и предложить улучшения.

Проект разработан на **Python** с использованием библиотек: **NumPy**, **Pandas**, **Scikit-learn**, **SciPy**, **Matplotlib**, **Seaborn**, **Surprise**. Можем запускаться в **Jupyter Notebook** или **Google Colab** для интерактивности.

Цель: создать рабочий прототип, иллюстрирующий плюсы и минусы каждого подхода, и предложить гибридизацию для повышения эффективности.

## Установка и Запуск

### Требования

- **Python 3.7+**
- **Jupyter Notebook** или **Google Colab**
- Библиотеки: `pip install numpy pandas scikit-learn scipy matplotlib seaborn tqdm surprise`

### Запуск

1. Скачайте датасет **Goodbooks-10k** (файлы: `ratings.csv`, `books.csv`, `tags.csv`, `book_tags.csv`) с исходного источника (Kaggle или Goodbooks).
2. Клонируйте репозиторий или скопируйте код в **Jupyter Notebook**.
3. Запустите код поэтапно: от EDA до оценки моделей.
4. Для демонстрационных визуализаций используйте `plt.show()` в Colab или локальном Jupyter.

Датасет должен находиться в той же директории, что и notebook.

## Этапы Реализации
### 1: Знакомство с Данными и EDA
- Загрузка таблиц: ratings.csv (пользователи и рейтинги), books.csv (книги), tags.csv (теги), book_tags.csv (связи).
- Анализ: распределение рейтингов (большинство высоких оценок), объем данных (около 6 млн отзывов), проверка связей (book_id, tag_id).
- Визуализация: распределение рейтингов, топ-тегов до и после очистки (удаление шумных тегов вроде "to-read").
- Очистка: удаление бесполезных тегов, фокус на топ-10000 значимых.
### 2: Базовые и Контентные Модели
- Популярность: рекомендации на основе среднего рейтинга и количества оценок.
- Контент-ориентированная: TF-IDF векторизация на основе названий книг и объединённых тегов. Косинусное сходство для рекомендаций похожих книг по книге.
### 3: Коллаборативная Фильтрация (Item-Based CF)
- Построение разреженной матрицы пользователь-книга (CSR matrix).
- Прогноз: взвешенное среднее рейтингов пользователя на похожих книгах (косинусное сходство).
- Рекомендация: агрегация сходств от оценённых книг пользователя.
### 4: Матричное Разложение- Использование библиотеки Surprise для SVD.
- Оценка: RMSE на тестовой выборке.
- Прогноз: для неизвестных книг пользователя сортировка по предсказанным оценкам.
### 5: Оценка и Сравнение Моделей- Разделение данных: train/test по пользователям.
- Метрики: Precision@10, Recall@10, nDCG@10 на пользователях с ≥4 рейтингами.
- Сравнение: популярность, контент, item CF, MF.
### 6: Гибридизация и Выводы
- Гибрид: контент для новых книг/пользователей, MF для устоявшихся, популярность для fallback.
- Итоги: Item CF доминирует по метрикам. Преимущества/недостатки представлены в таблице.
